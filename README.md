# NIVARAN – AI-Powered Grievance Redressal System

**NIVARAN** is an AI-powered grievance redressal and management platform designed to make complaint handling more transparent, efficient, and accountable within educational institutions. It provides a centralized system where students can submit grievances, track their progress, communicate with responsible authorities, and receive updates throughout the resolution process.

The platform enables officers to review and manage assigned grievances, prioritize cases based on urgency, and take appropriate action within defined timelines. Administrators can manage users, departments, and officer assignments while monitoring institutional performance through dashboards and reports.

NIVARAN integrates **Artificial Intelligence** to assist with grievance summarization, automatic classification, missing-information detection, officer recommendations, and grievance trend analysis. These capabilities help streamline complaint processing while keeping decision-making and final actions under authorized human control.

With role-based access control, secure authentication, grievance lifecycle tracking, SLA monitoring, and audit logs, NIVARAN aims to build a more reliable and transparent grievance redressal process.

### Key Features

- **AI-Powered Grievance Analysis:** Summarizes complaints, identifies categories, detects missing information, and assists in recommending responsible officers.
- **Student Dashboard:** Submit grievances, track complaint status, view updates, and monitor progress.
- **Officer Dashboard:** Review assigned cases, manage grievance status, prioritize urgent complaints, and communicate with students.
- **Admin Dashboard:** Manage users, departments, officer assignments, and institutional grievance statistics.
- **Role-Based Access Control:** Separate permissions for students, officers, and administrators.
- **Grievance Lifecycle Management:** Track cases from submission through review and resolution.
- **SLA Monitoring:** Monitor response and resolution deadlines and identify overdue grievances.
- **Transparency and Audit Trail:** Maintain activity records and provide visibility into grievance progress.
- **Notifications and Communication:** Keep users informed about important case updates.
- **Secure File Attachments:** Support relevant evidence and documents submitted with grievances.

### Technology Stack

- **Frontend:** React.js
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **AI Service:** Python, FastAPI, Google Gemini
- **Authentication:** JWT-based authentication and role-based authorization
- **Real-Time Communication:** Socket.IO
- **Development Tools:** Git, GitHub, VS Code

### Project Objective

The primary objective of NIVARAN is to simplify grievance management by replacing fragmented, manual complaint-handling processes with a centralized, AI-assisted platform. It aims to improve accountability, reduce processing delays, and provide students and institutional authorities with a clear view of every grievance's journey.
